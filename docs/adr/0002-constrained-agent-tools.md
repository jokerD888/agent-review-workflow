# ADR 0002: Agent 只能调用受限结构化工具

- 状态：已接受
- 日期：2026-08-12

## 决策

`arw-mcp` 仅向 Agent 暴露任务级的、具名输入输出工具。它不提供任意 shell，
也不暴露 push、rebase、reset、删除或任意目标的 merge。用户明确作出批准
结论后，Agent 可以代为记录；用户再单独要求合并后，Agent 可以调用受限的
本地合并工具。该工具从任务元数据推导目标，只允许版本未变化时执行
`--ff-only`，不解决冲突、不推送。

## 后果

- 允许的状态变化可审计、可验证，并能在核心状态机中统一约束。
- 人保留决定权，但不必亲自操作 CLI；Agent 只能执行用户明确表达的批准或合并意图。
- 用户仍可在自己终端中执行其他 Git 操作；外部合并目前不允许用未经验证的命令补记。
- MCP 层薄封装核心库，不应复制 Git 或状态机规则。
