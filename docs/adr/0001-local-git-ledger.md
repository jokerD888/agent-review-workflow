# ADR 0001: 使用本地 Git 元数据分支保存任务台账

- 状态：已接受
- 日期：2026-08-12

## 决策

任务台账存于受管理的 Git 分支 `arw/registry`，每个任务一份
`.agent-review/tasks/<task-id>.yaml`。核心程序以临时 worktree 读写该分支，
不会让用户日常切换到它。与某一台机器相关的信息放在 `.git/arw/`。

## 后果

- 元数据可随仓库备份和同步，且不污染产品分支。
- 元数据同步仍是显式 Git 操作；ARW 不会自行推送。
- Git 不可用或仓库没有初始提交时，ARW 必须拒绝创建任务并给出可操作诊断。
- 任务文件分散可减小并发冲突，但同一任务的并发写入仍由 ARW 锁和乐观版本检查保护。
